# Time modulo seven in the selected spatial RAAR cloud

The seven residue classes of one million consecutive unthinned states occupy similar finite clouds. First 400,000 states train the nearest-neighbor rule; last 400,000 states test it, separated by 200,000 steps. Accuracy is 0.1429225, close to the uniform 1/7 reference. This is not a mixing or ergodicity theorem. All three visual versions and all numerical arrays are retained.

The initial colorbar was clipped; the final figure uses per-class prediction accuracy instead and removes an overlapping axis label. Numerical arrays agree exactly. Run research/verify_raar_phase_review.py from the repository root. Source cloud and camera are in results/raar-circles/render.
