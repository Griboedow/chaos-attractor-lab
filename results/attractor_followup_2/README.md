# Four closer looks at existing attractors

| System | What the equations imply |
| --- | --- |
| [Newton iteration at a pole](newton/README.md) | Approach along either horizontal ray. Every sufficiently small shell in a geometric sequence contains all fifteen outcomes on that ray. Two 24° vertical sectors each lead to one root, a different root on each side. |
| [Straight geodesic on a fifteen-handle surface](geodesics/README.md) | The lap length stays at 62.517 as one wave amplitude changes. Linearized transverse amplification per lap grows without bound. At one regular parameter it exceeds 10⁹⁰. A sharp limiting law predicts how fast it grows. |
| [Pulsed optical cavity](optics/README.md) | Arbitrarily close to any point on one saddle’s stable surface, inputs reach all ten phases of the same cycle. On a single branch leaving the saddle, 41 certified slices reach all ten phases and force at least 36 distinct orbits that never converge to the cycle. |
| [Two alternating rings](annuli/README.md) | The plotted start enters the interior of the attractor after exactly two steps. The seven archived starts all enter within six steps, and their exact orbits never repeat. |

Each study links the original system, parameters, prior work and a reproducible check. [Earlier follow-up proofs](../low_hanging_20261122/README.md) · [Original portraits and equations](../../docs/chaotic-forms-20261122.md)
