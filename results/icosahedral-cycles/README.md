# Icosahedral cycle and measurement follow-up

Case 177 has two independently checked numerical unstable periodic orbits,
visiting three and five spiral-center neighborhoods. All 24 relative-shooting
attempts are retained, including 18 failures. Two candidates receive full-cycle
multiple shooting, RK4 refinement and 80/110-digit midpoint Taylor checks.
Neither periodic existence nor asymptotic chaos is interval certified here.

The radius-.12 itinerary in the older packet is unchanged. Its 194 apparently
reverse transitions each skip one radius-.2 visit. Radii .16 and .2 give the same
1,992-visit sequence and 60 directed edges; .25 and .3 add only the final visit.
Each geometric edge has one observed orientation, with two incoming and two
outgoing edges per center. This is a finite observation, not a Markov partition.

The first cycle figure had clipped titles; the final render fixes its margins.
No data were changed for that visual correction. The separate source snapshots
and portable scripts differ only in input/output and import path resolution.
